# Sol y Fruta

Sitio corporativo y comercial construido a partir del brief del cliente del 23/11/2026.

## Desarrollo

La primera versión es una web estática, responsive y en español. El punto de entrada es `index.html`.

## Unidades comerciales

- Canal Directo: mayoristas, multirrubros y supermercados.
- HORECA: hoteles, restaurantes, cafeterías, bares y servicios de alimentación.
- Exportación: consultas comerciales internacionales.

## Alcance y limitaciones

El formulario prepara un correo mediante el cliente de email del visitante; no existe backend ni envío automático. Las imágenes de producto son representaciones CSS conceptuales, no fotografías oficiales ni packshots reales. Se deben reemplazar por activos aprobados por Sol y Fruta antes de la publicación comercial definitiva.

Ver `/docs` para especificación, trazabilidad y estado de validación.
