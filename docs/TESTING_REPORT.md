# Informe de pruebas

## Ejecutado

- Inspección de repositorio vía GitHub: repositorio vacío confirmado antes de crear archivos.
- Revisión de la especificación PDF completa y sus referencias visuales.
- Implementación de HTML, CSS y JavaScript en un único archivo sin dependencias externas.
- Revisión estática del código y de los flujos principales definidos.

## No ejecutado / no verificado

- No se ejecutó un navegador automatizado ni pruebas E2E.
- No se ejecutó Lighthouse ni medición de Core Web Vitals.
- No se ejecutó axe/WAVE ni auditoría WCAG formal.
- No se ejecutó test en dispositivos físicos.
- No se comprobó el envío real de correo desde clientes de email.
- No se verificó publicación ni dominio productivo.

## Criterio de honestidad

La implementación inicial no debe considerarse una entrega final validada hasta ejecutar pruebas en navegador, obtener los activos oficiales y recibir aprobación de contenido del cliente.
