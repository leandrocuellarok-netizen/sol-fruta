# Estrategia UX

## Tarea principal del visitante

Identificar rápidamente si Sol y Fruta puede abastecer su tipo de negocio y abrir una conversación comercial con el canal correcto.

## Recorridos

- Distribuidor/supermercado → Canal Directo → contacto preseleccionado.
- Profesional gastronómico → HORECA → catálogo/formato de 2 litros cuando corresponda → contacto.
- Comprador internacional → Exportación → consulta comercial.
- Visitante general → empresa/productos/calidad → consulta general.

## Decisiones UX

- Tres unidades comerciales visibles y diferenciadas.
- CTA comercial reiterado sin saturar la navegación.
- Catálogo inicial breve con formatos respaldados por el PDF.
- Mensaje explícito de que la disponibilidad se consulta con el equipo.
- Formulario con campos simples y selección de canal.

## Accesibilidad inicial

HTML semántico, labels asociados, navegación por teclado, estado de menú anunciado, modal con cierre por Escape y estado de formulario anunciado. Revisión manual con lector de pantalla y auditoría WCAG 2.2 AA aún pendiente.
