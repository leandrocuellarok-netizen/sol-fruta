# SEO y GEO — primera etapa

## Implementado

- Idioma declarado como es-AR.
- Title y meta description.
- Canonical provisional a GitHub Pages; confirmar dominio final antes de publicar.
- Open Graph básico.
- Jerarquía semántica de encabezados.
- Secciones con IDs y enlaces internos.
- Formulario y controles etiquetados.

## Pendiente

- Incorporar schema.org Organization/Product solo con datos verificados.
- Optimizar fotografías reales con WebP/AVIF, dimensiones y alt descriptivo.

## Enfoque GEO

Mantener una entidad de marca consistente, describir con claridad la empresa, las tres unidades comerciales, productos y canales. Publicar capacidades, certificaciones y mercados solo cuando Sol y Fruta proporcione evidencia verificable. No prometer rankings ni citas en motores de IA.
